
# AACHIP-FTDI-8BIT-LOGIC-ANALYZER

AACHIP FTDI 8 BIT 邏輯分析儀是透過 FTDI 介面進行數位訊號擷取與波形觀察的工具，提供 8 通道訊號分析，供嵌入式系統開發、教學實驗與硬體除錯使用。

支援的 FTDI 型號、取樣率、擷取深度及觸發功能，請參考各版本發布說明。

## 應用情境

- 同時觀察最多 8 路數位訊號。
- 檢查 GPIO 電位變化與訊號間的時序關係。
- 觀察 UART、SPI、I²C 等介面的數位波形。
- 排查控制訊號、接線及通訊時序問題。
- 協助韌體開發與數位電路教學。
- 支援輸入電壓5V~3.3V。

通訊協定的自動解碼能力，以各版本實際功能為準。

## 基本使用流程

1. 安裝軟體及對應的 FTDI 驅動程式。
2. 確認 FTDI 裝置型號受目前版本支援。
3. 確認分析儀輸入電壓範圍與目標電路相容。
4. 依硬體接腳說明連接訊號通道，並與目標電路共地。
5. 啟動軟體，選擇裝置及適當的擷取設定。
6. 開始擷取，觀察各通道波形與時序關係。
7. 若版本提供儲存或匯出功能，可將結果保存供後續分析。

## 使用注意事項

- 本工具用於數位邏輯訊號觀察，無法代替示波器量測類比波形、過衝或訊號完整性。
- 不可直接連接超過硬體額定輸入範圍的訊號；必要時請使用電位轉換或適當保護電路。
- 擷取通道應設定為輸入，避免與目標電路同時驅動訊號。
- 取樣率需配合待測訊號並保留足夠餘裕，才能可靠辨識脈衝與訊號邊緣。
- 接線應盡量短，並保持良好的接地。
- 不同 FTDI 晶片與擷取模式的效能可能不同，請以版本說明及實測結果為準。
